BANKSHOT // ZERO is a projectile arena shooter written in Java and compiled for the browser with TeaVM.

Bounce shots off arena walls, dodge enemy fire, dash through danger, and choose upgrades between waves.

Play with a desktop keyboard and mouse: WASD/arrows to move, mouse to aim, hold left click to fire, Space to dash, P/Esc to pause, M to mute, and 1/2/3 to choose upgrades.

The `bankshot-zero-web.zip` asset is a complete browser build ready for a static web host or an itch.io HTML game upload. No Java runtime is required to play. Source code is MIT licensed.
