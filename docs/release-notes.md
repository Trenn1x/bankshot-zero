BANKSHOT // ZERO v1.1.0 adds mobile browser play with touch controls and layouts for portrait and landscape screens.

Move with the left stick, aim and fire by holding the right stick, and use the DASH button to dodge. Start, pause, toggle sound, restart, and choose upgrades with on-screen controls. The arena rotates to fit portrait screens, and the controls adapt when the viewport changes.

Desktop controls are retained: WASD/arrows to move, mouse to aim, hold left click to fire, Space to dash, P/Esc to pause, M to mute, and 1/2/3 to choose upgrades.

The game and renderer remain written in Java and compiled for the browser with TeaVM. The `bankshot-zero-web.zip` asset is a complete browser build for static hosting or itch.io. No Java runtime is required to play. Source code is MIT licensed.
